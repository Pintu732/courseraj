# Admin — No Coding Required

Open:
`YOUR-SITE/admin.html`

Sign in with the Firebase admin email/password you already created.

## Dashboard
See course/category counts.

## Courses
Click Add Course.
You can upload the thumbnail directly from your PC.
The browser automatically resizes and compresses it.
Fill course details and Save.

Edit/Delete works from the same page.

## Categories
Add, edit, hide, reorder, or delete categories.

## Website Settings
You can directly upload:
- Logo
- Hero background
- Favicon

You can also edit:
- Brand name
- Main Telegram
- Accent color
- Hero heading/subheading
- Announcement
- Section headings
- Footer
- SEO title/description

Normal website management requires no GitHub editing.
