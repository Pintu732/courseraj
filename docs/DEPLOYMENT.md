# Courseraj V4 Deployment — One-Time Setup

After this one-time deployment, normal content editing happens only in Admin.

1. Create a NEW public GitHub repository named `courseraj`.
2. Upload the CONTENTS of this folder to repository root.
3. GitHub Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Firebase Console → Firestore Database → Rules.
5. Paste the complete contents of `firestore.rules`.
6. Click Publish.
7. Wait for GitHub Pages deployment.
8. Open your live URL.
9. Open `YOUR-LIVE-URL/admin.html`.
10. Login with your Firebase admin email/password.
11. Website Settings → set Telegram, branding, logo, hero image.
12. Categories → create categories.
13. Courses → add courses.

After this, normal edits do NOT require code/GitHub.
